# Wintor — план проекта

> Рабочее название. Открытый BitTorrent-клиент для Windows на WinUI 3.
> Статус: v0.3 — Wintor в Microsoft Store; в 0.3 — воспроизведение во время загрузки ([#2](https://github.com/tarasenko-by/wintor/issues/2)) и «По завершении» (выключение после загрузок).

## 1. Цель

Современный, нативный для Windows 11 торрент-клиент: Fluent-дизайн, без рекламы,
без телеметрии, полностью открытый (GPL-3.0). Принимаем issue и PR от сообщества.

**Главное отличие — дизайн и удобство.** Большинство популярных клиентов (qBittorrent,
µTorrent, Transmission для Windows) выглядят как программы десятилетней давности:
плотные таблицы, десятки колонок, настройки, в которых тонешь. Wintor должен выглядеть
и ощущаться как приложение Windows 11: Mica, понятные карточки вместо таблиц,
разумные настройки по умолчанию, продвинутые опции убраны с глаз, но доступны.

**Не делаем:** встроенный поиск/каталог раздач. Клиент — это инструмент, а не
источник контента (важно и юридически, и для прохождения модерации Microsoft Store).

потом переименовывать дорого (namespace, Store, ссылки).

## 4. Ядро (торрент-движок)

Свой протокол BitTorrent не пишем — берём готовый открытый движок.

| | **MonoTorrent** | **libtorrent-rasterbar** |
|---|---|---|
| Язык | C#, чистый .NET | C++ |
| Лицензия | MIT (совместима с GPL) | BSD (совместима с GPL) |
| Подключение | NuGet-пакет, одна строка | Нужна обёртка C++ ↔ C# (P/Invoke / C++/CLI), своя сборка под x64/ARM64 |
| Зрелость | Рабочий, но развивается медленно (3.0.2, авг. 2024) | Эталон: qBittorrent, Deluge |
| Порог входа | Низкий | Высокий |

**Решение:** начинаем с **MonoTorrent**, но приложение общается с движком только
через свой интерфейс `ITorrentEngine` в `Wintor.Core`. Если упрёмся в
производительность или нехватку функций — пишем второй адаптер на libtorrent,
UI не трогаем.

```
UI (WinUI)  →  ViewModels  →  ITorrentEngine  →  MonoTorrentEngine (сейчас)
                                              ↘  LibtorrentEngine  (возможно, потом)
```

## 5. Архитектура и структура репозитория

```
Wintor.sln
src/
  Wintor.App/              WinUI 3: окна, страницы, ViewModels, ресурсы
  Wintor.Core/             Модели, ITorrentEngine, сервисы — без ссылок на UI
  Wintor.Engine.MonoTorrent/  Реализация ITorrentEngine
tests/
  Wintor.Core.Tests/       Юнит-тесты (xUnit)
docs/
  ROADMAP.md
```

- **MVVM** — `CommunityToolkit.Mvvm` (генераторы `[ObservableProperty]`, `[RelayCommand]`).
- **DI** — `Microsoft.Extensions.Hosting` / `DependencyInjection`.
- **Контролы** — `CommunityToolkit.WinUI` (настройки, сегменты и т.д.).
- **Хранение** — настройки в JSON; состояние раздач (resume data) — средствами движка
  в `%LocalAppData%\Wintor`.
- **Локализация** — `.resw`, сразу `en-US` и `ru-RU`.

## 6. MVP (v0.1)

Минимум, с которым клиентом уже можно пользоваться:

1. Добавить торрент: `.torrent`-файл, magnet-ссылка, drag & drop.
2. Выбор папки загрузки и файлов внутри раздачи при добавлении.
3. Список раздач: имя, размер, прогресс, скорость ↓/↑, пиры, ETA, статус.
4. Пауза / продолжить / удалить (с файлами или без).
5. Детали раздачи: файлы, пиры, трекеры.
6. Сохранение состояния: после перезапуска всё продолжается.
7. Глобальные лимиты скорости.
8. Настройки: папка по умолчанию, порт, лимиты, тема (светлая/тёмная/системная).
9. Регистрация как обработчик `.torrent` и `magnet:`.

## 7. После MVP (бэклог)

- Web UI / удалённое управление (далёкая перспектива) — современная замена Devices из µTorrent (управление с телефона).

### GPL-3.0 и Microsoft Store

Вопрос, который надо закрыть **до приёма первого чужого PR**: условия Store
(DRM, EULA магазина) часто считают несовместимыми с «чистой» GPL-3.0. Пока весь
код ваш — вы как автор можете публиковать его где угодно. Когда появится чужой
код, публиковать его в Store можно только с разрешения авторов. Варианты:

- **Дополнительное разрешение** (GPL-3.0, раздел 7) в `LICENSE`: явно разрешить
  распространение через магазины приложений. Простой и распространённый путь.
- **DCO** (`Signed-off-by` в коммитах) или **CLA** — контрибьютор подтверждает права.

Рекомендация: GPL-3.0 + исключение для app store + DCO. Код при этом остаётся
полностью открытым, форки тоже обязаны быть открытыми.

### Бренд и форки

## 9. Сообщество

Главная цель проекта — чтобы в него вкладывались другие разработчики.
Лицензия на это почти не влияет, влияет удобство участия.

**Когда открываем репозиторий:** на этапе M3, когда приложение уже качает торренты
и выглядит аккуратно. До этого разрабатываем сами, а к M3 готовим всё, что ниже.

1. **Сборка за 10 минут.** В README: какие компоненты Visual Studio поставить → открыть
   `Wintor.sln` → F5. Никаких ручных шагов, которых нет в инструкции.
2. **С чего начать.** Задачи с метками `good first issue` / `help wanted`: переводы,
   мелочи в UI, новые колонки, иконки.
3. **Куда идёт проект.** Публичный roadmap (этот файл или GitHub Projects), чтобы
   можно было взять задачу себе.
4. **Быстрые ответы.** Отвечать на issue и PR в течение пары дней, хотя бы «спасибо,
   посмотрю». Долгое молчание — главная причина, по которой контрибьюторы уходят.
5. **Понятная архитектура.** `Core` / `Engine` / `App` разделены, чтобы работать над
   частью проекта, не разбираясь в остальном. Описать это в `docs/ARCHITECTURE.md`.
6. **Место для обсуждений.** GitHub Discussions для идей и вопросов, issues — для багов
   и конкретных задач. Позже Telegram/Discord.
7. **Красивая витрина.** Скриншоты и короткое GIF в README.
8. **Переводы.** Crowdin или Weblate (бесплатны для open source): переводчикам не нужно
   знать C#, это самый простой вход в проект.
9. **Признание.** Список контрибьюторов в README (all-contributors), упоминания в
   заметках к релизам.

## 10. Распространение

1. **GitHub Releases** — MSIX и/или zip (x64, ARM64). Без подписи сертификатом
   Windows будет показывать предупреждение SmartScreen — для альфы допустимо.
2. **Microsoft Store** — Store подписывает пакет сам, сертификат не нужен.
   Регистрация разработчика для физлиц сейчас бесплатная.
   ⚠️ Риск: торрент-клиенты проходят модерацию тяжелее (был прецедент удаления
   торрент-приложения из Store). Снижаем риск: нет встроенного поиска контента,
   описание про легальное использование (дистрибутивы Linux, open-source файлы и т.п.).
3. **winget** (позже) — встроенный в Windows менеджер пакетов, как `apt` в Linux:
   пользователь пишет `winget install Wintor` и получает приложение. Публикация
   бесплатная — PR с манифестом в репозиторий `microsoft/winget-pkgs`, ссылающимся
   на ваш файл из GitHub Releases.
