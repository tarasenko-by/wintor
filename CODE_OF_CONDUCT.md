# Code of conduct

Wintor follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to issues, pull requests, discussions and any other project space.

In short: be kind and patient, assume good intent, criticise ideas rather than people, and remember that many
contributors are new to open source or write in a second language. Harassment, insults and personal attacks
are not tolerated.

## Reporting

If someone's behaviour bothers you, contact the maintainers privately through the repository's
**Security** tab → **Report a vulnerability** (it is private and reaches only the maintainers; say it is
a conduct report), or by email to the address on the maintainer's GitHub profile. Reports are handled
confidentially. The maintainers may edit or remove content and warn, suspend or ban participants, as described
in the Contributor Covenant's enforcement guidelines.
